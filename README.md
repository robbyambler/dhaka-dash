# Dhaka Dash · ঢাকা দৌড়

You're Rupa, a university student with a backpack and a class to catch. Between you and the lecture hall are ten of Dhaka's wildest roads: rickshaws, painted buses, CNGs, and the occasional driver going the wrong way down the lane. Hop through the traffic, ride the boats, grab a cup of tea, and get there in one piece. It's a classic lane-crossing arcade game, with a lot of Dhaka in it.

Play it: https://robbyambler.github.io/dhaka-dash/

## Controls

- Move: arrow keys or WASD (on a phone, the on-screen pad)
- Confirm: Enter or Space (the OK button on a phone)
- Pause: P (the II button on a phone). Esc goes back.
- M mutes the sound, L switches between English and Bengali

## What's in it

- 10 levels, each based on a real part of Dhaka
- HP and lives, so one bump doesn't end your run
- Tea and biscuit upgrades
- Wrong-way drivers who will not be reasoned with
- New Game+ once you've won
- English and Bengali, switchable any time

## Run it locally

    npm install
    npm run dev
    npm run test
